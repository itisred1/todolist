# Todo List

A simple and lightweight **Todo List** web application built with HTML, CSS, and JavaScript.

## 📁 Project Structure

```text
todolist/
├── index.html
├── style.css
└── script.js
```

### Files

* **`index.html`** — Main structure and content of the Todo List.
* **`style.css`** — Styling and layout.
* **`script.js`** — JavaScript logic for managing todos.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and clean interface
* No frameworks or dependencies required

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/USERNAME/todolist.git
```

2. Open the project folder:

```bash
cd todolist
```

3. Open `index.html` in your browser.

That's it — no installation or build process is required.

* HTML5
